Information brief · checked 4 October 2026

Local voice means the microphone does not become a cloud service.

Voice is optional, visible, and fail-closed. The studio enables it only after the browser proves that recognition for the selected language can run on this device.

The short promise: while the studio reports Private on-device speech ready, microphone audio is processed by the browser on this device. The page receives recognized text, does not receive or record the audio stream, and does not send the audio or text anywhere.

The exact privacy boundary

The studio requests recognition with processLocally: true, checks the browser’s local language-pack status, and refuses to start if that contract is unavailable. It does not silently fall back to the older online form of the Web Speech API.

The browser may use the network to load this website and, after a separate browser permission, to download a language model. That download contains no microphone audio. Once the page and model are cached, the learning activity and recognition can operate without a recognition server.

Scope matters: “local voice” is a claim about microphone recognition in this studio. Clicking an outside link or loading a new version of the site is still ordinary web traffic.

Compatibility changes quickly. The studio tests the API at runtime instead of assuming support from a browser name or version.

Language learning without pretending to grade an accent

The current Firefox model manifest explicitly supports English, French, German, and Vietnamese. The studio offers those four choices. Speaking a number checks the answer immediately, and a correct answer advances after a short visible pause. Seeing the intended text and action can provide immediate, low-stakes evidence that this recognizer found the speech intelligible.

That is not the same as measuring pronunciation quality. Recognition can be affected by microphones, room noise, age, accent, dialect, disability, and model bias. The studio therefore treats transcription as practice feedback, never as a grade, diagnosis, or claim that one accent is the correct one.

Learner control is part of the implementation

  • Keyboard and touch are always the default and remain fully usable.
  • A learner deliberately presses a voice button and answers the browser’s microphone prompt.
  • The selected model download requires a separate browser-controlled confirmation.
  • The microphone state remains visible and voice can be stopped immediately.
  • Voice stops when the page is hidden or the practice set ends.
  • No learner account, audio recording, analytics script, or advertising tracker is used.

What “free and local” costs

There is no per-minute speech API bill for this path. The cost moves to the device: a one-time model download, disk space, memory, processor or GPU time, battery, and the engineering needed to support an experimental interface.

Mozilla’s current manifest lists an approximately 141 MB English streaming model and a 785 MB multilingual model. Those artifacts and browser behavior can change, so the browser’s own download prompt is authoritative.
